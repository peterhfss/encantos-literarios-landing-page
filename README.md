## Sobre

O **Encantos Literários** é uma landing page sobre um clube literário proposto como desafio prático da Rocketseat. Ele consiste em desenvolver uma página atrativa para apresentar os benefícios do clube, assim como o kit que é entregue , como também os preços das assinaturas. Nesse projeto além de sua estrutura em HTML, foi possível praticar sobre animações com CSS.

## Tecnologias
