## Sobre

O **Encantos Literários** é uma landing page sobre um clube literário proposto como desafio prático da Rocketseat. Ele consiste em desenvolver uma página atrativa para apresentar os benefícios do clube, assim como o kit que é entregue , como também os preços das assinaturas. Nesse projeto além de sua estrutura em HTML, foi possível praticar sobre animações com CSS.

## Tecnologias

### Frontend

- 🎨 **[TailwindCSS](https://tailwindcss.com/)** — Framework CSS utility-first para estilização e responsividade.
- 🖥️ **[HTML](https://developer.mozilla.org/pt-BR/docs/Web/HTML)** — Linguagem de marcação de Hipertexto utilizada para estruturar todo o conteúdo de um site.

## Como Executar

1. Clone o repositório: 

   ```bash
   git clone git@github.com:peterhfss/encantos-literarios-landing-page.git
   cd seu-repositorio
   ```

2. Instale as dependências:

    ```bash
   npm install
   # ou
   pnpm install
   ```
3. Inicie a aplicação:


    ```bash
   npm run dev
   # ou
   pnpm run dev
   ```
